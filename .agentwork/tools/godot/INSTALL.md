# Install Godot Tool

## What gets installed
- `.shared/commands/godot.md`
- optional thin wrappers for Codex / Antigravity

## Install
```bash
python3 install-tool.py godot -p <path>
python3 install-tool.py godot -p <path>
python3 install-tool.py godot -p <path>
```

## After install
- ensure `godot` CLI is available
- run `/godot init`
- default outputs should land under `.tmp/godot/`
