> 目录用途：记录跨 Session 可复用、且相对稳定的项目事实、约束、入口和约定。
>
> - ✅ 写：稳定约束、关键入口、兼容性红线、常用命令、已确认的全局约定
> - ❌ 不写：当次任务细节、方案对比、临时 workaround、迁移过程、最近一次执行记录

## 入口约定
- 启动阶段只默认读取当前 `index.md`
- 不预读全部 `project/*.md`
- 当任务涉及某个项目或目录时，再读取对应的 `*.md`
- 当第一次确定将读取或修改的目标路径后，必须立即对照当前索引映射；若命中条目，先读取对应文档
- 每个 project 文档保持轻量，只记录少量但重要的稳定事实

## 索引约定
- 默认先维护当前 `index.md`
- 当某个项目或子域稳定事实明显增多时，再新增对应的 `*.md` 文件
- 在当前 `index.md` 里维护“目录/主题 → 文档”的简单映射
- 新增或更新 `project/*.md` 时，优先遵循 `.shared/templates/project.md`
- 索引映射优先使用固定三元组：`命中` / `读取` / `用途`
- 新增的 project 文档应只记录长期稳定事实，不记录当次任务上下文
