# Semantic Navigation

在当前项目内做代码定位时，优先使用“语义定位”而不是纯字符串搜索。

## 目标
- 更快定位定义、引用、符号与影响范围
- 降低大范围误改风险
- 在复杂任务中减少无效上下文加载

## 默认策略
1. 先确定目标符号或文件边界
2. 优先使用支持 definition / references / symbols / diagnostics 的语义能力
3. 只有在语义能力不够时，再退回纯文本搜索
4. 修改前先确认影响范围，再开始编辑

> 平台自带语义能力不足或需要跨文件调用图时，可按需安装 codegraph 工具包（安装后见 `.shared/mcp/codegraph.md`）。

## 适用场景
- 重命名
- 追调用链
- 查引用
- 读大型代码库中的局部结构
