数据织网

展示埋点、事件流、清洗、策略路由、分析和模型服务之间的密集管线。

index.md diagram.mmd diagram.svg

业务背景

交易、履约和运营动作都会沉淀为事件数据，数据域需要同时支撑实时响应和离线分析。

结构说明

  • 采集入口负责把埋点和业务事件汇入统一事件流
  • 加工与策略层负责清洗、标准化和路由，为不同消费场景分发数据
  • 承载层同时提供实时缓存、数仓和模型评分结果，覆盖低延迟查询与长期分析
  • 消费与动作层把数据回送给推荐、分析看板和运营触达，形成业务闭环

关键边界

  • 清洗层与策略路由决定口径一致性，是数据质量的第一道关口
  • 实时缓存面向在线服务，数仓面向经营分析，模型评分面向策略执行，三者职责要明确分离
