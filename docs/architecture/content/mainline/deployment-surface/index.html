部署分层

对比发布入口、控制面、策略网格、运行单元和内部运维工具的层次关系。

index.md diagram.mmd diagram.svg

业务背景

电商平台的交付链路需要把发布入口、控制策略和运行单元分层隔离，避免业务变更直接穿透到运行面。

分层说明

  • 顶层是发布入口与环境边界
  • 中层是控制面和策略网格
  • 底层是运行单元和运维工具

关键边界

  • 发布控制台负责版本发布、环境选择和变更审批，不直接承担运行治理
  • 策略网格是控制面和运行面的分界，配置、流量和开关应通过这里统一下发
