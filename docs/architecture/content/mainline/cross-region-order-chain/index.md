# 跨域订单长链路

## 业务背景

跨仓订单通常横跨流量入口、风控校验、库存锁定、拆单编排、配送履约、签收回传和经营结算，链路长且参与域多。

## 主链路

- 流量与下单阶段承接会场、商品详情和购物车结算，把交易意图转换成可校验请求
- 校验与风控阶段处理地址、优惠和风险决策，确保订单可以进入支付与落单
- 交易与拆单阶段完成主单生成、库存锁定、跨仓拆单和履约编排，是跨域协同的核心控制段
- 履约与配送阶段负责仓内拣配、干线路由和末端配送
- 反馈与经营阶段沉淀签收、通知、评价和结算结果，形成后续经营分析输入

## 异常分支

- 风控异常订单会转入人工审核后再回到支付授权
- 拆单阶段如果出现缺货改配，会先生成替代仓建议再进入履约编排
- 签收后的逆向申请会回流到售后入口，并影响最终结算归档
